# Immutable recipe matrix capability (disabled)

The installed bridge supports marked weights in native recipe constant sections. This experiment isolates copies of immutable checkpoint projection matrices; it never marks request/KV/Engram state or routed expert banks. Views and released meta placeholders remain untouched, prepared matrix aliases are rebound explicitly, and baseline metadata isolation is checked. The original logical-constant serialization uses the private per-rank cache.

Four-layer native compilation produces actual constant sections. The allweight candidate changes the native hidden/pre state while preserving SWA; no timer ran. Separate common C1 primitive diagnostics fail when the installed compiled cache attempts to restore a missing perrecipe constant file. The narrowed BF16/FP32 two-dimensional MME variant fails the same reuse contract. A numerical conclusion has not been established.

`VLLM_HPU_DSV41_DSPARK_RECIPE_CONSTANTS` defaults to0. The direction is stopped: do not promote, add it to the pending gains, or recut marking/layout/cache variants. The opt-in code and public SDK const-section inspector preserve the reproducible capability failure for a separate compiler investigation.
